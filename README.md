# Darussalam Ridho - Portfolio Website

Selamat datang di repository portofolio pribadi saya! Website ini dibuat untuk menampilkan perjalanan karier, keahlian, dan proyek-proyek saya sebagai Junior Web Developer.

## 🚀 Live Demo
Website ini dapat diakses secara langsung melalui: **[achmaddarussalamridho.my.id](https://achmaddarussalamridho.my.id/)**

## 🛠️ Teknologi yang Digunakan
Portofolio ini dibangun untuk memastikan performa tinggi dengan desain visual yang modern, menggunakan:
- **HTML5 & CSS3** untuk struktur dan tata letak.
- **Vanilla JavaScript (ES6+)** untuk interaksi dan animasi dinamis.
- Desain kustom dengan efek *Glassmorphism* dan interaksi 3D.
- Responsif penuh untuk semua ukuran layar (Mobile & Desktop).

## ⚙️ CI/CD & Deployment
Repository ini dikonfigurasi menggunakan **GitHub Actions** untuk *Continuous Deployment (CD)*. Setiap kali ada perubahan kode yang di-*push* ke branch `master`, sistem akan secara otomatis melakukan deploy file terbaru ke server hosting melalui FTP.
